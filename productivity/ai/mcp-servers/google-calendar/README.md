# Tiny google calendar mcp server

Small read-only google calendar mcp server.

## Usage

```bash
UTIL_AI_MCP_GOOGLECALENDAR_TOKEN # mcp server http bearer token
UTIL_AI_MCP_GOOGLECALENDAR_ACCOUNT_FILE # path to google service account json file
UTIL_AI_MCP_GOOGLECALENDAR_MAX_RESULTS # max results to fetch per request
UTIL_AI_MCP_GOOGLECALENDAR_CALENDAR_ID # google calendar id
```
